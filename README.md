# Plant Disease Detection using CNN

## Project Overview
This project uses a Convolutional Neural Network (CNN) to classify plant leaf images into disease categories using TensorFlow and the PlantVillage dataset.

## Objectives
- Load and preprocess plant leaf images.
- Train a CNN model for image classification.
- Predict plant disease categories from uploaded images.
- Display the top predicted categories through a Gradio interface.

## Technologies Used
- Python
- TensorFlow and Keras
- TensorFlow Datasets
- NumPy
- Matplotlib
- Gradio

## Methodology
1. Load the PlantVillage dataset.
2. Resize images to 128 × 128 pixels and normalize pixel values.
3. Prepare training and validation datasets.
4. Build and train a CNN model.
5. Evaluate the model and visualize training results.
6. Test predictions using leaf images.
7. Create an interface using Gradio.

## How to Run
Open the notebook in Google Colab and run its cells in order. The dataset will be loaded using TensorFlow Datasets.

## Important Note
Predictions are for educational purposes and are not a confirmed plant disease diagnosis.
